# Human Variant Quiz / 人类配置差异测评

> 你是“究极人类”吗？——同一种刺激，不同版本的大脑与身体。

一个科普 + 娱乐向的**二分式个体差异测评**静态网站：回答 N 道二选一题目，按“每项满分 100 分”的评分表计算平均分，生成总分、称号、分类得分、分项明细与可复制的分享文本。

## 免责声明（重要）

- 本测评是**科普 / 娱乐内容，不是医学诊断**，不评价生理优劣，不提供治疗建议。
- 所有特质都是**连续谱**，二选一只是简化。
- “100 分”仅代表在本评分体系下“现代功能覆盖更好 / 风险更低 / 感觉运动处理更完整”，**不代表医学上更高级**。
- 中性神经多样性（ASMR、联觉、绝对音感、心盲症等）**不是疾病或缺陷**。
- 免责声明在首页、测评结果页、关于页均显著展示。

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Next.js（App Router）+ TypeScript，纯静态输出，无后端 / 无登录 / 不收集用户数据 |
| 样式 | Tailwind CSS v4 + shadcn/ui |
| 图表 | Recharts（分类平均分横向条形图） |

| 部署 | Vercel（标准 Next.js 部署） |

## 评分方法（框架 v2：常模参照）

设计原则是**方向与程度分离**——不做“每题手填分数”：

- **方向**：每题显式声明唯一“好极”（`goodOption`），这是压缩到最小的价值判断，逐题标注依据层级，可审计。
- **程度**：由两个客观量决定，无魔法数字：
  - **依据层级权重**（`rationale`）：健康/安全风险 ×3 > 现代功能适应 ×2 > 感知带宽 ×1 = 中性/趣味宣言 ×1（词典序优先级借用公共卫生测量惯例：疾病/伤残负担 > 功能不便 > 增益 > 偏好）；
  - **好极人群频率**（`goodFrequency`，全球粗估）：只用于常模百分位，不参与完成度。

### 两个输出数字

1. **配置完成度（总分）** = Σ(权重 × 是否好极) ÷ 总权重 × 100，保留 1 位小数。
   全部好极 = 恰好 100 = 字面意义的“究极人类”（当前 39 题下概率 ≈ 39 万亿分之一）。
2. **常模百分位** = 超过百分之多少的“模拟人类”。以各题好极频率构造加权泊松二项分布，
   **动态规划精确求解**（非蒙特卡洛），按中位秩约定输出。

分类得分 = 类别内加权完成度。核心评分函数是纯函数：`calculateResult(answers, questions)`，
答题不完整时返回 `null`（结果页据此拦截，“全部答完才能出结果”）。

### 称号阈值

按模拟人群分布校准（当前 39 题：均值 ≈61.6，σ ≈7.3，即 100/73/62/51 对应 全好/前6%/中位/前93%）：

| 完成度区间 | 称号 | 模拟人群占比 |
|---|---|---|
| 100（全部好极） | 究极人类候选 | ≈0%（39 万亿分之一） |
| 73 – 99.9 | 高配多面手 | ≈6.3% |
| 62 – 72.9 | 标准高配 | ≈39.5% |
| 51 – 61.9 | 特色配置型 | ≈46.7% |
| < 51 | 极端偏科型 | ≈7.5% |

> ⚠️ 更换题目/权重/频率后必须重新校准阈值（均匀乱选期望 50 分 → 极端偏科型；乱选低于人群典型值是因为乱选者会随机丢掉多数人的好极）。
> 校准方法见 `src/lib/scoring.ts` 中 `TITLE_TIERS` 的注释。

### 相对 v1 数据的修订记录

合并重复题（晕动症 ×2、咖啡因 ×2）、归类修正（耳虫→大脑、氢氰酸嗅觉→感官、心盲→大脑）、
睡眠时型好极翻转为“中间型”、氢氰酸频率按文献修正（20%–40% 闻不到）、删除体味题的
“社交成本”表述并降为中性层级。v2.1–v2.7 逐题改写可自评性差/带社会赞许偏差的题干（氢氰酸、苦味、
恐音症、甜腻、耳垢、睡眠时型）。v2.8 扩容 26→39 题（新增失歌症、麝香闻感、卷舌、动耳、搭车拇指、
冰淇淋头痛、雷诺现象、不安腿、蚊叮偏好、音乐寒颤、哈欠传染、幽灵震动、电影落泪），阈值随之重新校准。
详见 `src/data/questions.ts` 头部注释。

## 扩充题目

题目数据与 UI 解耦：只需向 `src/data/questions.ts` 的数组追加符合 `Question` 类型的对象，评分、答题页、结果页、分享文本全部自动适配，**无需改动任何 UI 代码**（改分值分布后记得重新校准称号阈值）。

## 隐私保护

- 站点不收集、不上传任何数据：无后端、无账号、无 Cookie、**无持久化存储**。
- 答题进度存于 **sessionStorage**（当前标签页会话内存）：刷新与站内跳转不丢进度，
  关闭标签页即被浏览器自动销毁，设备上不留答案历史；“重新测试”即刻清空。
  不使用 localStorage 的原因：其持久性会留下无必要的生理特质档案（负债 > 功能）。
  v1/v2 的 localStorage 遗留数据会在首次访问时自动清除。
- 分享文本提供两档隐私级别：
  - **只公开得分（默认）**：完成度、称号、常模百分位、分类完成度；
  - **包含差异明细**：额外列出每题的选择与好极/对照极标记。
- 分享偏好同样仅会话内记忆，不跨会话保留。

## 可访问性

- 移动端优先，桌面端自适应。
- 选项为 `role="radiogroup"` / `role="radio"`，可 Tab 聚焦、Enter/Space 选择，带 `aria-checked`。
- 进度条、meter、图表均有 ARIA 标签；图表配有文字表格视图，不依赖颜色/动画传达信息。
- 复制成功反馈使用 `aria-live="polite"`。
